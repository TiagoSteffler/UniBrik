## 📖 Sobre o Projeto
O **UniBrik** surgiu com o propósito de oferecer uma ferramenta de utilidade pública para a comunidade acadêmica da Universidade Federal de Santa Maria (UFSM). 

Esse projeto surgiu de uma entrega acadêmica, que acabou sendo aprimorada para se tornar algo funcional. Atualmente, grupos de WhatsApp, Facebook e outras redes sociais são usados para anunciar produtos, mas raramente são apropriadas para tal. O **UniBrik** resolve isso sendo um Web App (PWA) simples, moderno, **100% gratuito** e **restrito a estudantes e servidores**, onde você pode vender, comprar, doar ou trocar itens de forma segura.

➡️ Acesse o site [**aqui**](https://unibrik.vercel.app/#/) em seu navegador!

---

## Principais Funcionalidades

A plataforma foi desenvolvida para oferecer:

- 🔒 **Acesso Exclusivo e Seguro:** Login unicamente via Google utilizando e-mails institucionais (`@acad.ufsm.br`, `@inf.ufsm.br`, `@ufsm.br`).
- 🛍️ **Gestão de Anúncios:** Crie, edite e gerencie seus próprios anúncios, informando título, descrição, fotos, preço, estado de conservação e métodos de entrega.
- 💬 **Chat em Tempo Real:** Comunique-se diretamente com vendedores e compradores de forma rápida, sem precisar expor seu número de telefone pessoal.
- 🔎 **Busca e Filtros:** Encontre o que precisa de forma rápida utilizando a pesquisa por palavras-chave e filtros de categoria.
- ❤️ **Favoritos:** Salve os anúncios que mais lhe interessaram para acessá-los depois.
- 📱 **Progressive Web App (PWA):** Instale o aplicativo diretamente no seu celular ou computador pelo navegador para uma experiência mais fluida.

## Tecnologias Utilizadas
- **Frontend:** Vue.js 3, Vue Router
- **Backend & Banco de Dados:** Firebase (Authentication, Firestore, Storage)
- **Estilização:** CSS3 Moderno
- **Proteção do site:** reCAPTCHA V3
